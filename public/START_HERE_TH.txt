Zipspeed Space — ชุดใหม่ล้วน

ชุดนี้เป็นเว็บ/PWA ไม่มีโปรเจกต์ Android Kotlin, Gradle, VIP หรือหน้าจอเก่า
มี index.html เป็นหน้าหลักเพียงจุดเดียว

ติดตั้ง:
1. แตก ZIP ลงโฟลเดอร์ว่าง ใช้โฟลเดอร์ใหม่นี้แทนโปรเจกต์เก่า
2. เปิดผ่านโฮสต์ HTTPS หรือ localhost เพื่อใช้ PWA และ API ที่ต้องการ secure context
3. ถ้าจะใช้โฟลเดอร์เก่า ให้ย้ายหรือลบไฟล์โปรเจกต์เก่าก่อน แล้วจึงแตกชุดนี้ลงไป
   การแตกทับ ZIP ไม่ลบไฟล์ที่ไม่ได้อยู่ใน ZIP
4. หากยังเห็นหน้าเก่าบนโฮสต์ ให้ล้างข้อมูลเว็บไซต์ของ Zipspeed แล้วเปิดใหม่
   การล้างข้อมูลเว็บไซต์จะลบประวัติผลทดสอบที่เก็บไว้ในเบราว์เซอร์นั้น

ระบบ: Speed, Video throughput estimate, Status, พิกัด Map, System Test, History, Share, Settings
ภาพสไตล์ 3D ใช้ Canvas/CSS ไม่ใช่ไฟล์ Blender
ต้องใช้อินเทอร์เน็ตเพื่อวัดความเร็ว; ใช้ Cloudflare endpoint เดิม ไม่มีผลสุ่ม
ไม่ใช่ APK/AAB และไม่สามารถเปิด build เป็น Android ด้วย Gradle ได้
ชุดนี้ยังไม่ผ่านการทดสอบทุกเบราว์เซอร์หรืออุปกรณ์จริง ไม่รับรองว่าปลอดบั๊ก
ผ่านการตรวจ syntax และตรรกะ GO/STOP, บันทึกผล, HTTP error ด้วยข้อมูลจำลองก่อนหน้า
รายละเอียดภาษาอังกฤษยังแปลไม่ครบ; Video ไม่ใช่สตรีมจริง; Map เป็นพิกัดไม่ใช่แผนที่
